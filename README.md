# hasanpekedis.github.io

My personal site, built as an interactive terminal. Type `help` (or tap a command) to explore: `whoami`, `about`, `experience`, `projects`, `skills`, `education`, `cv`, `contact`, `lang tr|en`, `theme dark|light|matrix`.

Plain HTML, CSS and JavaScript, no build step. Open `index.html` locally or serve the folder with any static server.

Edit content in `terminal.js` (`PROJECTS` and the `T.en` / `T.tr` copy).
